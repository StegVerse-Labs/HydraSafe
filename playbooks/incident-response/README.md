# Incident Response Documentation Playbook

This playbook is a documentation and evidence-preservation framework. It is not an emergency-response command system and does not direct physical response, override site procedures, or confer incident-command authority.

During an actual incident, personnel must follow the facility's approved emergency procedures and applicable emergency-services/incident-command authority. HydraSafe records may capture references, timestamps, evidence, decisions, and later review dispositions without becoming operational authority.
